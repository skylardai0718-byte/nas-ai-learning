## Knowledge Score

等级根据答题证据自动计算：客观题看对错，简答题和场景题看你自己的批改等级。
每个等级都有最低答题量要求，所以刚开始学的时候分数不会虚高。

尚未开始的领域会显示为 `Beginner（尚未开始）`，并且不计入综合等级 —— 前几周大多数领域还没开始是正常的。
