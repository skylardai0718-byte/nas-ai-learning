## Day 1：Network、LAN 与 WAN

**新概念：** Network、LAN、WAN

**总时长：** 55 分钟

### 今日目标

- 理解「网络」的本质是设备之间能互相传递数据。
- 分清 LAN（本地网络）和 WAN（广域网）的边界。
- 能在示意图中正确摆放手机、NAS、路由器与互联网。

### 学习（25 分钟）

先建立最基础的直觉：**网络就是一群能互相通信的设备。**

然后区分两个范围：

```text
LAN（Local Area Network，局域网）
  →  你家里的网络：手机、电脑、NAS、电视都在里面
  →  特点：范围小、速度快、自己管

WAN（Wide Area Network，广域网）
  →  连接不同地点的网络：互联网就是最大的 WAN
  →  特点：范围大、需要运营商、自己管不了
```

关键位置：**路由器是 LAN 和 WAN 的交界处。** 它一边连着家里的设备，一边连着运营商。

画一张示意图：

```text
[ 手机 ]  [ 电脑 ]  [ NAS ]
      \      |      /
       \     |     /
        [ 路由器 ]
             |
        —— WAN / 互联网 ——
```

### 复述（12 分钟）

- 用自己的话解释 LAN 和 WAN 的区别。
- 回答：为什么说路由器是「交界处」？
- 画出家里设备与互联网的位置关系。

### 测试（13 分钟，不给答案）

2. 判断：家里的 NAS 属于 LAN 中的设备。
3. 判断：互联网本身就是一个巨大的 LAN。
4. 家里的设备和外部的服务器通信时，数据要经过哪个设备？
5. 为什么 LAN 内的传输速度通常比访问互联网快得多？

## Day 2：Router 与 Switch

**新概念：** Router、Switch

**总时长：** 55 分钟

### 今日目标

- 理解路由器负责「在不同网络之间转发」，交换机负责「在同一网络内转发」。
- 知道家用路由器为什么常被称为「一体机」。
- 能判断什么情况下需要额外加一台交换机。

### 学习（25 分钟）

两者的核心区别只有一句话：

```text
Switch（交换机）  →  在同一个网络内部转发数据
Router（路由器）  →  在不同网络之间转发数据
```

用小区类比：

- **交换机是楼里的过道**：让同一栋楼里的住户互相走动。
- **路由器是小区的门卫**：决定谁能进出小区、怎么和外面联系。

**家用路由器为什么叫「一体机」？** 因为它其实把好几样东西集成在一个盒子里：

```text
家用路由器 =
  路由器功能    （连接内外网）
+ 交换机功能    （多个网口互连）
+ 无线接入点    （Wi-Fi 信号）
+ 常见还有：DHCP 服务、防火墙、NAT
```

所以严格说，你家里那个「路由器」是一台多合一设备。

**什么时候需要加交换机？** 当网口不够用时。交换机可以扩展有线接口数量，但它不会带来新的网络，只是把同一个网络的口子变多。

### 复述（12 分钟）

- 用一句话说清路由器和交换机的分工。
- 回答：为什么家用路由器被称为「一体机」？
- 回答：NAS 有 4 个网口，想接 8 台设备，应该加什么？

### 测试（13 分钟，不给答案）

1. Router 和 Switch 分别负责什么范围的数据转发？
2. 判断：交换机可以连接两个不同的网络。
3. 判断：家用路由器只做路由这一件事。
4. 网口不够用时，应该增加哪种设备？
5. 为什么说交换机加进来不会改变网络的边界？

## Day 3：IP 地址：内网与公网

**新概念：** IP Address、Private IP、Public IP

**总时长：** 55 分钟

### 今日目标

- 理解 IP 地址的作用是「在网络中定位一台设备」。
- 分清私有地址和公网地址的使用范围。
- 能在示意图中标出内网与公网地址。**本周不做子网计算。**

### 学习（25 分钟）

IP 地址就是设备在网络中的「门牌号」。没有它，数据不知道该送到哪。

分两类：

```text
Private IP（私有地址）
  →  只在本地网络内部使用，比如 192.168.x.x、10.x.x.x
  →  全世界的家庭网络都在重复使用这些地址

Public IP（公网地址）
  →  运营商分配给你的、在互联网上唯一的地址
  →  通常只有一个，由路由器持有
```

关键理解：**你家里每台设备都有自己的私有地址，但它们对外共用路由器的那一个公网地址。**

```text
[ 手机 192.168.1.11 ]  [ NAS 192.168.1.10 ]
              \              /
             [ 路由器 ]
        内网口：192.168.1.1
        外网口：公网地址（运营商分配）
                  |
            —— 互联网 ——
```

> **注意**：上面全是示例地址。你真实的公网 IP 不要写进任何公开笔记。

### 复述（12 分钟）

- 分别解释私有地址和公网地址的作用范围。
- 回答：为什么全世界那么多家庭可以重复使用 `192.168.1.x`？
- 回答：家里有三台设备上网，它们各自有公网地址吗？

### 测试（13 分钟，不给答案）

1. IP 地址的作用是什么？
2. 判断：`192.168.1.10` 是一个可以直接在互联网上访问的地址。
3. 判断：家里每台设备都有自己独立的公网地址。
4. 手机和 NAS 在同一个家庭网络中，它们用什么类型的地址互相识别？
5. 路由器为什么需要同时拥有内网地址和外网地址？

## Day 4：DHCP 与 DNS

**新概念：** DHCP、DNS

**总时长：** 55 分钟

### 今日目标

- 理解 DHCP 解决「地址从哪来」，DNS 解决「名字怎么变地址」。
- 知道这两个服务通常由路由器提供。
- 能解释「改了路由器设置之后要重新获取地址」这类现象。

### 学习（25 分钟）

两个服务解决两个不同的问题：

```text
DHCP  →  自动给设备分配 IP 地址
DNS   →  把域名翻译成 IP 地址
```

**DHCP（动态主机配置协议）**

如果每台设备都要手动填地址，家里来客人连个 Wi-Fi 都要配置一次。DHCP 让设备一接入网络就自动拿到地址。

- 由路由器（或专门的服务器）提供。
- 分配的是「租约」—— 地址有使用期限，到期会续租或重新分配。
- 这也是为什么重启路由器后，设备的地址有时会变。

**DNS（域名系统）**

你能记住 `nas.local` 或 `example.com`，但记不住 `93.184.216.34` 这样的数字。DNS 就是那个「电话簿」，把名字翻译成地址。

```text
你输入：example.com
↓ DNS 查询
得到：某个 IP 地址
↓
浏览器向这个地址发起请求
```

两个服务都由路由器默认提供，也可以指定成别的服务器。

### 复述（12 分钟）

- 用一句话分别解释 DHCP 和 DNS。
- 回答：为什么新设备连上 Wi-Fi 就能上网，不需要手动配置？
- 回答：如果 DNS 出问题，会有什么表现？

### 测试（13 分钟，不给答案）

3. 判断：把域名翻译成 IP 地址是 DNS 的工作。
4. 能打开某个网站，但输入域名打不开，输入 IP 却可以，可能是哪个服务出了问题？

## Day 5：一次局域网访问的完整路径

**新概念：** （综合应用，无新概念）

**总时长：** 55 分钟

### 今日目标

- 把本周所有概念串成一条完整的访问路径。
- 能回答「手机为什么能在家找到 NAS」。
- 完成本周周测与 Weekly Review。

### 学习（20 分钟）

把本周的内容合成一条链路。假设你在家用手机访问 NAS 上的照片：

```text
1. 手机连上 Wi-Fi
   → 向路由器请求一个 IP 地址（DHCP）

2. 手机拿到地址，比如 192.168.1.11
   → 和 NAS（192.168.1.10）处于同一个 LAN

3. 你在手机上输入 NAS 的名字或地址
   → 如果是名字，需要 DNS 把它翻译成 IP

4. 数据出发
   → 同在一个 LAN 内，路由器/交换机负责转发

5. NAS 收到请求，返回照片
   → 完全在这个家庭网络内部完成，没有经过互联网
```

**关键结论：在家访问 NAS，数据不出门。**

```text
[ 手机 ]  →  [ 路由器/交换机 ]  →  [ NAS ]
    全部发生在 LAN 内部
```

这也解释了一个现象：**在家访问 NAS 很快，出门就访问不了。** 因为「出门」意味着你不在这个 LAN 里了 —— 这正是下周（Week 5）的主题。

- 为什么手机能「找到」NAS？

- 为什么出门之后就访问不到了？
