# 第二周详细计划：读懂 NAS 硬件规格

## 本周目标

完成后，你应能：

1. 逐项解释 CPU 规格卡上的 Core、Thread、Clock 和 TDP。
2. 从软件兼容性、功耗和使用场景比较 x86 与 ARM，不纠缠指令集细节。
3. 区分内存的容量、代际（DDR4 / DDR5）和纠错能力（ECC）。
4. 分清存储的介质（HDD / SSD）、连接方式（SATA / NVMe）和外形规格（M.2）。
5. 解释 PCIe 与 Lane，理解 x1 / x4 / x8 / x16 的差别。
6. 看到 `Intel N150 / 16GB DDR5 / 2×SATA / 1×M.2 NVMe / PCIe 3.0 x1` 这样的规格串时能逐项解释，**也知道它没有告诉你什么**。

> 每天 45–60 分钟。测试题不立即公布答案；作答后，再按“完全理解 / 基本理解 / 表面理解 / 存在误区”批改。
>
> 本周不比较跑分，不背具体型号。目标是**读懂规格在说什么**，而不是判断哪台机器更强。

## Day 1：CPU 规格卡上的 Core、Thread、Clock、TDP

**新概念：** Core、Thread、Clock、TDP

**总时长：** 55 分钟

### 今日目标

- 看到“4 核 4 线程”和“4 核 8 线程”时，知道差别在哪里。
- 不再把 GHz 当成可以跨型号直接比较的数字。
- 理解 TDP 为什么对一台 24 小时开机的 NAS 特别重要。

### 学习（25 分钟）

先用厨房类比建立直觉：

- **Core（核心）**：厨房里有几位厨师。
- **Thread（线程）**：每位厨师能同时照看几个灶。
- **Clock（频率）**：做菜的节奏有多快。
- **TDP（热设计功耗）**：厨房的发热量，以及需要多大排风。

再用一颗具体的 CPU 逐项核对：`Intel N150 / 4 核 4 线程 / 最高 3.6GHz / TDP 6W`。

- 4 核 4 线程：四个厨师，一人一个灶，没有超线程。
- 最高 3.6GHz：节奏的上限，平时会低很多。
- 6W：发热很小，所以很多迷你 NAS 不需要风扇。

本周不比较跑分，只看规格本身在描述什么。

### 复述（12 分钟）

- 用厨房类比解释四个词，然后不用类比再准确解释一遍。
- 回答：4 核 8 线程等于 8 个核心吗？为什么？
- 回答：为什么不能只看 GHz 判断两颗 CPU 谁更快？

### 测试（13 分钟，不给答案）

1. Core 和 Thread 分别指什么？两者是什么关系？
2. 判断：一颗 5GHz 的 CPU 一定比一颗 3GHz 的 CPU 快。
3. 判断：TDP 就是这颗 CPU 的实际耗电量。
4. 一台 NAS 常年开机、放在客厅，TDP 低有什么好处？
5. 只看“4 核”这一项，能否判断它处理照片缩略图的速度？还缺哪些信息？

## Day 2：x86 与 ARM 有什么不同？

**新概念：** x86、ARM

**总时长：** 55 分钟

### 今日目标

- 知道 x86 和 ARM 是两种不同的 CPU 架构，软件需要针对它们分别编译。
- 理解为什么大多数成品 NAS 用 x86，而很多低功耗设备用 ARM。
- 能从软件兼容性、功耗和场景三方面比较，而不是背指令集名词。

### 学习（25 分钟）

- **x86**：Intel 和 AMD 使用的架构，个人电脑、服务器和大多数成品 NAS 都是它。
- **ARM**：手机、树莓派、Apple 自研芯片和不少低功耗迷你主机使用它。

只比较三个维度：

| 维度 | x86 | ARM |
|---|---|---|
| 软件兼容性 | 最广，几乎所有软件都有版本 | 需要专门编译，部分软件没有 ARM 版 |
| 功耗与发热 | 通常更高 | 通常更低 |
| 典型场景 | 成品 NAS、需要转码或跑虚拟机 | 轻量文件共享、低功耗常年开机 |

关键点：**软件是按架构编译的。** 一个为 x86 打包的 Docker 镜像，在 ARM 上不一定能直接运行。

### 复述（12 分钟）

- 用 2 分钟向普通用户解释 x86 和 ARM 的区别。
- 回答：为什么“ARM 比 x86 省电”不等于“ARM 一定更好”？
- 回答：打算在 NAS 上跑一套现成的 Docker 服务，架构会带来什么风险？

### 测试（13 分钟，不给答案）

1. x86 和 ARM 分别常见于哪些设备？
2. 判断：为 x86 编译的软件可以直接在 ARM 设备上运行。
3. 判断：ARM 架构的 CPU 一定比 x86 慢。
4. 同样功耗下想做硬件转码，选哪种架构更省心？为什么？
5. 买 ARM NAS 之前，最该先确认什么？

### 今日产出（5 分钟）

完成一张 x86 / ARM 比较表，并写一句结论：**在什么情况下我会选哪一种。**

## Day 3：内存的容量、代际与纠错

**新概念：** RAM、Capacity、DDR4、DDR5、ECC

**总时长：** 55 分钟

### 今日目标

- 分清内存的三个独立维度：容量、代际、是否 ECC。
- 理解容量决定“够不够”，而不是“快不快”。
- 知道 ECC 解决的是什么问题，以及它不能解决什么。

### 学习（25 分钟）

先回到 Week 1 的结论：**RAM 是临时工作区，断电就清空。**

然后拆开三个维度：

- **容量（Capacity）**：能同时装下多少“正在使用的东西”。NAS 上影响同时运行多少服务、Docker 容器、照片索引和虚拟机。
- **代际（DDR4 / DDR5）**：两代内存规格。DDR5 更新、带宽更高，但**主板决定支持哪一种，两者不能混插**。
- **ECC**：纠错内存，能发现并纠正部分位错误，降低数据被静默写坏的风险。需要 CPU 和主板同时支持。

对家用 NAS 来说，**容量通常比代际更重要**：16GB DDR4 一般比 8GB DDR5 更实用。

### 复述（12 分钟）

- 用一句话分别解释容量、代际和 ECC。
- 回答：为什么“内存越大越快”这个说法不准确？
- 回答：装了 ECC 内存，还需要备份吗？

### 测试（13 分钟，不给答案）

1. 内存的三个维度分别是什么？
2. 判断：DDR5 内存条可以插进只支持 DDR4 的主板。
3. 判断：内存容量越大，NAS 的运行速度就一定越快。
4. 同时跑多个 Docker 容器时开始变卡，优先怀疑哪一项不够？
5. ECC 能防止数据丢失吗？它和备份是什么关系？

## Day 4：存储的介质、连接方式与外形

**新概念：** HDD、SSD、SATA、NVMe、M.2

**总时长：** 55 分钟

### 今日目标

- 把“介质、连接方式、外形规格”三个维度分开，不再混为一谈。
- 知道 M.2 只是一种外形，它既可能是 SATA，也可能是 NVMe。
- 能根据用途判断该选 HDD 还是 SSD。

### 学习（25 分钟）

本周最容易混淆的一点是：下面三组词**不在同一个维度上**。

```text
介质（数据存在什么上）    →  HDD、SSD
连接方式（数据怎么传）    →  SATA、NVMe
外形规格（长什么样子）    →  2.5 寸、M.2
```

- **HDD**：机械硬盘，容量大、单价低，适合大容量长期存储；有机械结构，怕震动。
- **SSD**：固态硬盘，随机读写快、无机械结构，适合系统盘、缓存和频繁访问的数据。
- **SATA**：成熟的存储连接方式，HDD 和部分 SSD 都用它。
- **NVMe**：为 SSD 设计的高速连接方式，速度远高于 SATA。
- **M.2**：一种板卡外形。**M.2 插槽里的硬盘可能是 NVMe，也可能是 SATA**，必须看规格说明。

典型 NAS 配置：SSD 装系统、HDD 存数据。

### 复述（12 分钟）

- 用三个维度重新描述“一块 M.2 NVMe SSD”。
- 回答：为什么说“M.2 就是 NVMe”不准确？
- 回答：给家庭影音库选存储，HDD 和 SSD 各自适合放在哪？

### 测试（13 分钟，不给答案）

3. 判断：SATA 是一种硬盘外形规格。

## Day 5：PCIe 与 Lane

**新概念：** PCIe、Lane、x1 / x4 / x8 / x16

**总时长：** 55 分钟

### 今日目标

- 理解 PCIe 是一条高速通道，Lane 是这条通道里的车道。
- 知道 x1 / x4 / x8 / x16 描述的是通道宽度，而不是速度等级。
- 能读懂一张简化规格表，并知道哪些信息它没有提供。

### 学习（20 分钟）

- **PCIe**：主板上连接高速设备的总线，M.2 NVMe、网卡和扩展卡都走它。
- **Lane（通道）**：PCIe 的基本单位，可以理解成车道数。
- **x1 / x4 / x8 / x16**：表示这条插槽占几条 Lane。数字越大，理论上能同时传输的数据越多。

一条重要常识：**PCIe 有代际**。PCIe 3.0 x4 和 PCIe 4.0 x4 的宽度相同，但每一代的速度不同。

所以 `PCIe 3.0 x1` 的意思是：第三代 PCIe，只有一条 Lane。它通常够接一块网卡或做轻度扩展，但**不适合期待它跑到顶级 NVMe 的速度**。

```text
CPU / 芯片组
↓ 提供
PCIe 通道（分成若干 Lane）
↓ 分配给
M.2 插槽、网卡插槽、扩展卡插槽
```

### 复述（12 分钟）

做一段 2–3 分钟口头讲解，回答：

- PCIe 和 Lane 分别是什么？
- x16 和 x1 的差别是什么？
- 为什么规格表上写“PCIe 3.0 x1”值得注意？
- 只看“支持 NVMe”，能否判断它有多快？

### 周测（13 分钟，不给答案）

1. 判断：x16 插槽的传输能力一定比 x1 强，与 PCIe 代际无关。
2. 判断：Lane 数量越多，能同时传输的数据越多。
3. 用一句话解释 `PCIe 3.0 x1`。
4. NVMe 硬盘插在 PCIe 3.0 x1 的通道上，可能受到什么限制？
5. 规格表写“1×M.2 NVMe”，它还缺哪些信息才能判断速度？
6. 用不超过 150 字，逐项解释 `Intel N150 / 16GB DDR5 / 2×SATA / 1×M.2 NVMe / PCIe 3.0 x1`。
