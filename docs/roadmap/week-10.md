## Day 1：AI、机器学习与神经网络

**新概念：** AI、Machine Learning、Neural Network

**总时长：** 55 分钟

### 今日目标

- 说清 AI、机器学习、神经网络三者的包含关系。
- 理解「机器学习」和「传统编程」的根本区别在于谁总结规则。
- 知道神经网络是实现机器学习的一种方法，而不是机器学习的全部。

### 学习（25 分钟）

很多人把 AI、机器学习、神经网络当成三件并列的事，其实它们是**层层包含**的：

```text
AI（人工智能）
├── 机器学习（Machine Learning）
│   ├── 神经网络（Neural Network）
│   │   └── 大语言模型（LLM）    ← 下周、下周之后一直用到
│   ├── 决策树、支持向量机……
│   └── 其他方法
└── 早期方法（规则系统、专家系统……）
```

**AI 是最外面的圈**：只要让机器表现出「像人一样做事」的能力，都算 AI。早期靠人工写死规则，也能算 AI。

**机器学习是其中一种做法**：不再由人把规则一条条写出来，而是**给机器大量例子，让它自己从例子里总结规律**。

```text
传统编程：人写规则  +  数据  →  答案
机器学习：数据  +  答案（例子）  →  规则（模型）
```

**神经网络**是实现机器学习的一种具体方法，它的灵感来自大脑神经元之间的连接。它非常擅长从大量数据里找出复杂的规律，所以成了现在最主流的一种方法 —— 但**它不等于机器学习的全部**。

本周不涉及任何数学推导。你只需要先建立这张包含关系图。

## Day 2：LLM、模型与参数

**新概念：** LLM、Model、Parameter

**总时长：** 55 分钟

### 今日目标

- 解释 LLM 是什么、它和神经网络的关系。
- 破除两个常见误解：模型不是普通数据库、Parameter 不是用户设置项。
- 说清参数是「模型内部学到的数值」，而不是你能在设置界面里改的选项。

### 学习（25 分钟）

**LLM（大语言模型，Large Language Model）** 是一种专门处理语言的神经网络，用海量文本训练而成。

```text
神经网络（一大类方法）
└── LLM：专门处理语言的、规模很大的神经网络
```

**模型（Model）**，就是训练这件事的产物 —— 一堆数值的集合，它把从数据里总结出的规律「存」了下来。你给它输入，它按这些数值算出输出。

这里有个必须破掉的误解：**模型不是普通数据库。**

```text
数据库：存的是原始资料，你查什么它给你什么
模型：   存的是从资料里总结出的规律，你问它，它按规律算出一个新答案
```

数据库里能原样查到的句子，模型里**并没有存**。它是「学会了怎么说」，不是「背下了这些话」。

第二个必须破掉的误解：**Parameter（参数）不是用户设置项。**

很多人看到「参数」，以为是软件里那些可以勾选、填写的配置选项。不是。**参数是模型内部那些通过学习得来的数值。**

```text
用户设置项（Settings）：你在界面上改的，比如主题、语言
模型参数（Parameter）：训练时机器自己调整出来的，用户通常不会去动
```

一个模型的参数量，通常用「B」来表示（B 是十亿的意思）。你可能听过「一个 7B 参数的模型」这样的说法 —— 意思是它内部有大约七十亿个这样的数值。参数量衡量的是模型的规模，不是它的质量。

## Day 3：Token 与上下文窗口

**新概念：** Token、Context Window

**总时长：** 55 分钟

### 今日目标

- 理解 Token 是模型处理文字的基本单位。
- 理解上下文窗口是模型一次能「看到的」内容上限。
- 分清「上下文窗口」和「永久记忆」，这是本周最容易搞错的一点。

### 学习（25 分钟）

**Token（词元）** 是模型处理文字时用的基本单位。

模型并不像人那样一个一个字地读。它会把文字切成一块一块的小片段，每一块就是一个 token。一个 token 可能是一个完整的词，也可能是半个词，或者一个标点。

```text
模型看到的不是：  我  爱  学  习  AI
模型看到的是：    [我][爱][学习][AI]     ← 每个方括号是一个 token
```

因为切法和你熟悉的「字数」不一样，所以**估算长度时用 token 数比用字数更准**。

**上下文窗口（Context Window）** 是模型一次能处理的 token 数量上限 —— 包括你输入的内容 **加上** 它输出的内容，加起来不能超过这个上限。

```text
上下文窗口 = 一次对话能装下的总量（输入 + 输出）
超出上限 → 最早的内容会被挤出去
```

这里要破掉本周最顽固的一个误解：**上下文窗口不等于永久记忆。**

```text
上下文窗口：这一次对话里能同时看到的内容上限（临时）
永久记忆：  跨对话、长期保留的信息（普通模型默认没有）
```

关掉对话、或内容超出窗口，之前说过的东西模型就不一定再「记得」了。它**没有内置一个长期记忆库**。你能接着聊，是因为这次对话的内容一直在窗口里，而不是因为它记住了你。

## Day 4：训练与推理

**新概念：** Training、Inference

**总时长：** 55 分钟

### 今日目标

- 分清训练和推理是两件目的完全不同的事。
- 比较二者对资源的需求差异。
- 说清「在 NAS 上使用现成模型，通常是在推理，不是在训练」。

### 学习（25 分钟）

**训练（Training）** 是让模型「学会」的过程：拿海量数据反复调整内部参数，直到它表现变好。

**推理（Inference）** 是让训练好的模型「干活」的过程：参数已经固定，你输入内容，它算出输出。

```text
训练：数据 → 反复调整参数 → 得到一个模型
推理：加载现成的模型 → 输入 → 输出（参数不再改变）
```

这两个词最容易混，但它们的差别很大：

```text
目的不同：
  训练 → 把模型做出来
  推理 → 把模型用起来

资源需求不同：
  训练 → 极重，需要大量算力、显存和时间，常常是很多张专业显卡跑很久
  推理 → 轻得多，一台家用设备也可能跑得动一个小模型

参数是否改变：
  训练 → 一直在变（这就是学习）
  推理 → 固定不变
```

**这就是本周最实用的一条结论：**

> 你在 NAS 上跑一个现成的模型来问答，那是在**推理**，不是在训练。你并没有在「训练 AI」，你只是在「使用一个已经训练好的模型」。

理解这一点，你才能明白为什么家用设备跑得动推理，却几乎不可能自己训练一个大模型 —— 因为训练的资源需求高好几个数量级。
