# 第十七课：路由器与交换机

> 本课的一句话结论：**交换机在同一个网络内部转发数据，路由器在不同网络之间转发数据 —— 一句话就把两者的分工说清了。**

## 1. 今天学习什么

今天只掌握 2 个核心概念：

1. **交换机（Switch）**：在同一个网络内部转发数据，扩展有线接口。
2. **路由器（Router）**：在不同网络之间转发数据，是 LAN 与 WAN 的关口。

你今天要建立的核心结构是：

```text
同一个网络内部     →  Switch 负责转发
不同网络之间       →  Router 负责转发
```

以及一个重要认知：**你家里那个「路由器」其实是一台多合一设备。**

```text
家用「路由器」通常同时承担：
├── 路由      连接 LAN 与 WAN
├── 交换      提供多个网口
├── 无线接入  发出 Wi-Fi 信号
├── DHCP      给设备分配地址
└── 防火墙    基本的安全过滤
```

## 2. 为什么要学

昨天你知道了路由器是 LAN 和 WAN 的交界。但家里的网络设备不止路由器一个 —— 你可能还见过交换机、无线接入点、光猫。

这些盒子长得差不多，功能却分属不同层次。分不清它们，会遇到这些问题：

- 网口不够用，买交换机还是买路由器？
- 为什么有人说「加交换机不会扩大网络」？
- 为什么家里既有光猫又有路由器？能不能只留一个？
- NAS 有很多网口，插在路由器上和插在交换机上有区别吗？
- 为什么重启路由器能解决很多网络问题？

理解这两个设备的层次差别，才能回答这些问题。

**更重要的是：这是「分层思维」在网络上的一次应用。** 第 1 周你学过「硬件 → 操作系统 → 应用」的分层，这里学的是网络设备的分层。

## 3. 小白解释

### 3.1 交换机：楼里的过道

**交换机（Switch）** 的工作范围是**同一个网络内部**。

用一个最简单的场景理解：你家里有 4 台设备要接网线，但路由器只有 3 个网口。怎么办？

接一台交换机。交换机会把 4 台设备连起来，让它们互相通信。

**交换机做的事情非常专一：**

```text
数据进来   →  看目的地址   →  只发给需要的那台设备
```

它不理解「互联网」，不分配地址，也不管你能不能上网。它只负责在**同一个网络内部**把数据准确送到。

用公寓楼类比：

> 交换机就像**楼里的过道**。它让同一栋楼里的住户能互相走动 —— 你从 301 走到 305 只需要穿过走廊。但过道不能帮你出楼，去别的城市得走大门。

### 3.2 路由器：小区的门卫

**路由器（Router）** 的工作范围是**不同网络之间**。

它做的事比交换机复杂：

- **判断方向**：这个数据是要发往楼内还是楼外？
- **转发**：发往楼外的，交给运营商；发往楼内的，转给对应设备。
- **地址转换**：让内部设备共用对外的那个公网地址（第 5 周会详细讲 NAT）。
- **分配地址**：通常还兼任 DHCP 服务（Day 4）。

用小区类比：

> 路由器就像**小区的门卫兼大门**。楼里的事他不怎么管，但所有进出小区的都要经过他。他还负责告诉快递员「3 号楼在哪」—— 相当于把外部地址对应到内部设备。

### 3.3 为什么家里的路由器是「一体机」

严格来说，你家那个盒子里装着好几样东西：

```text
[ 你家那个「路由器」]
├── 路由器功能     ← 连接内外网，转发
├── 交换机功能     ← 那几个网口就是个小交换机
├── 无线接入点     ← 发出 Wi-Fi
├── DHCP 服务      ← 给设备分配 IP
└── 防火墙         ← 基本的入站过滤
```

**所以「路由器」这个词在家用语境下其实是个简称**，指的是一台多合一设备。

这也解释了一个常见现象：**重启路由器能解决很多问题** —— 因为它同时是好几个服务的载体，任何一个卡住都可能影响上下的所有设备。

### 3.4 交换机扩展的是「口数」，不是「网络」

这是本课最重要的一点。

很多人以为「加个交换机，网络就变大了」。实际上：

```text
加交换机之前：3 个设备在同一个 LAN
加交换机之后：7 个设备还在同一个 LAN
```

**交换机只是让同一个网络里的接口更多了。** 网络的边界没有变，地址范围没有变，「谁能直接访问谁」的关系也没有变。

**打个比方**：过道多修几条，楼里住户之间的走动更方便了，但楼的边界没变，也没多出一栋楼。

## 4. 技术解释

### 4.1 交换机（Switch）

交换机工作在数据链路层，主要通过 MAC 地址（设备的物理地址）转发数据帧。

关键特性：

- **学习能力**：交换机会记录「哪个 MAC 地址在哪个端口」，之后只把数据发往对应的端口，而不是广播给所有口。
- **不隔离网络**：所有连接的设备仍在同一个网络内，共享同一个地址段。
- **不分配地址**：不给设备发 IP，不提供 DHCP。
- **即插即用**：普通交换机通常不需要配置。

**用途**：扩展有线接口数量。典型的时机是「路由器网口不够用了」。

### 4.2 路由器（Router）

路由器工作在网络层，通过 IP 地址在不同网络之间转发数据包。

关键特性：

- **连接不同网络**：至少有两个接口，一个朝内（LAN）、一个朝外（WAN）。
- **维护转发表**：决定数据往哪个方向转发。
- **网络边界**：默认情况下，外部无法直接访问内部设备 —— 这是重要的安全边界。
- **常兼任其他服务**：DHCP、NAT、防火墙、无线接入。

### 4.3 光猫又是干什么的

家用场景里常常见到「光猫 + 路由器」两个盒子。简单理解：

```text
光猫      →  把运营商的信号转成你家能用的网络信号
              （负责「接入 WAN」这一步）
路由器    →  管理你家 LAN，并连接光猫
```

有些光猫本身带有路由功能，所以会出现「光猫直接当路由器用」的情况 —— 这在配置上可能带来双重地址转换，是排障时容易忽略的一环。**家用场景不需要深入，但要知道这个盒子的存在。**

### 4.4 什么时候该加什么

| 需求 | 该加什么 |
|---|---|
| 网口不够用 | 交换机 |
| Wi-Fi 覆盖不到某个房间 | 无线接入点 / 另一台路由器做 AP |
| 想让网络分段（如隔离智能家居设备） | 路由器 / VLAN（进阶，本周不展开） |
| 想连接两个不同的网络 | 路由器 |

**最简单的判断**：问自己「我需要扩展接口数量，还是需要连接另一个网络？」

## 5. 类比

继续用**小区**的类比，把两个设备放在一起看：

```text
[ 你家 3 号楼 ]
├── 走廊、楼梯      →  交换机
│   作用：让楼内住户互相走动
│   边界：不出楼
│
└── 楼门 / 门卫     →  路由器
    作用：进出小区都要经过
    边界：楼内 ↔ 楼外
```

现在假设楼里住户变多了，走廊不够宽：

- **加一条走廊（加交换机）**：住户之间走动更方便，但楼还是那栋楼，住户还是同一批人。
- **这不是加了新楼**。

再假设你想和隔壁小区通信：

- **这需要走小区的大门（路由器）**，不是多修走廊能解决的。

**核心差别**：交换机扩展的是「同一个空间内的通路」，路由器连接的是「不同的空间」。

## 6. NAS 实际场景

### 6.1 三个真实判断

**场景一：NAS 有 2 个网口，想接 6 台设备，但路由器只有 4 个口**

**加一台交换机。** 需求是「扩展接口数量」，属于同一网络内部的事，交换机正好。

需要注意：交换机本身也有速度规格（千兆、2.5G 等）。如果 NAS 是 2.5G 网口，配一台千兆交换机会成为瓶颈 —— **这里用到了第 2 周的「瓶颈」思维**。

**场景二：把 NAS 插在路由器上还是交换机上**

在同一个 LAN 内，两者都能让设备互通。

差别在于**路径长度**：插在路由器上，数据可能还要经过路由器内部转发；插在交换机上，同交换机内的设备互通可能更直接。

对家用场景，这个差别通常不明显。**更有影响的是接口速度是否匹配，而不是插在哪个设备上。**

**场景三：为什么重启路由器能解决很多问题**

因为那台设备同时承载了路由、交换、无线、DHCP 等多个功能。任何一个功能卡住（比如 DHCP 分配表异常、无线模块假死），都会表现为「网络出问题」。

**重启等于让所有这些服务重新开始。** 但这只是临时手段 —— 如果频繁需要重启，说明有更深层的问题。

### 6.2 排障时的分层思路

延续前几周的方法，网络问题也可以分层：

```text
设备连不上 Wi-Fi              →  无线接入层
设备连上了但拿不到 IP 地址    →  DHCP 层
拿到了 IP 但只能访问局域网    →  路由器到 WAN 那一段
能访问局域网但访问不了某个网站 →  DNS 或对方服务的问题
```

**这张表的价值在于：它能让你的排查从「网坏了」变成「哪一层坏了」。**

### 6.3 一个常被忽略的点

第 2 周学过 PCIe 通道共享，第 3 周学过 RAID 与备份。网络这边也有类似的概念：**家用路由器的多个功能共享同一套硬件资源。**

当 NAS 在做大量数据传输时，路由器的 CPU 和内存可能成为瓶颈，进而影响 Wi-Fi 的稳定性。**这就是「一体机」的代价** —— 方便，但各功能之间会互相影响。

## 7. 常见误区

### 误区一：交换机可以连接两个不同的网络

不能。交换机只在同一个网络内部转发。要连接两个不同的网络，必须用路由器。这是本课最核心的一条区分。

### 误区二：加了交换机，网络范围就变大了

不会。交换机只是让同一网络内的接口数量变多。网络边界、地址范围、访问关系都没有改变。**变多的是「口数」，不是「网络数」。**

### 误区三：家用路由器只做路由这一件事

它同时承担路由、交换、无线接入、DHCP、防火墙等多项功能。**这也是为什么重启它往往能「治好」各种看起来无关的问题。**

### 误区四：网口不够就该买路由器

不一定。如果是单纯的接口不够，买交换机更便宜也更简单。只有当你需要「连接另一个网络」或「做网络分段」时，才需要路由器。

### 误区五：NAS 插在交换机上会更快

在同一个 LAN 内，插哪里通常差别不大。真正影响速度的是**接口速率是否匹配**（千兆还是 2.5G）、网线质量、以及 NAS 自身的网卡能力。**别把「换个口」当成提速手段。**

## 8. 知识地图

昨天画了边界，今天往边界上填设备：

```text
网络
├── 范围划分                （Day 1）
│   ├── LAN 局域网
│   └── WAN 广域网
├── 设备                    ← 今天在这里
│   ├── Switch 交换机        （同一网络内部转发，扩展口数）
│   └── Router 路由器        （不同网络之间转发，LAN/WAN 边界）
│       家用「路由器」= 路由 + 交换 + 无线 + DHCP + 防火墙
├── 地址
│   ├── Private / Public IP  （Day 3）
│   └── DHCP / DNS          （Day 4）
└── 综合
    └── 局域网访问路径        （Day 5）
```

本课与其他课的连接：

```text
Week 1 Day 2  →  网卡是硬件角色之一
Week 1 Day 3  →  数据流：理解数据经过哪些环节
Week 2 Day 1  →  瓶颈：路由器也可能成为瓶颈
     ↓
Week 4 Day 1  →  LAN 与 WAN 的边界
Week 4 Day 2  →  路由器与交换机的分工（本课）
     ↓
Week 4 Day 3–4 →  地址、DHCP、DNS
Week 4 Day 5   →  完整访问路径
     ↓
Week 5         →  NAT、端口转发：数据如何进出 LAN
```

今天只需要真正记住一句话：

> **交换机在「同一张网里」转发，路由器在「两张网之间」转发** —— 网口不够加交换机，要连别的网络才用路由器；而你家里那个「路由器」，其实是一台多合一设备。
