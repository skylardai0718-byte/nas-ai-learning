# 第十六课：网络、LAN 与 WAN

> 本课的一句话结论：**网络就是「一群能互相通信的设备」，而 LAN 和 WAN 是按范围划分的两类网络 —— 你家的设备在 LAN 里，LAN 通过路由器接到 WAN（互联网）上。**

## 1. 今天学习什么

今天只掌握 3 个核心概念：

1. **网络（Network）**：能够互相传递数据的设备集合。
2. **LAN（Local Area Network，局域网）**：范围小、自己管理的本地网络。
3. **WAN（Wide Area Network，广域网）**：跨越较大范围、连接不同地点的网络。

你今天要建立的核心结构是：

```text
[ 手机 ]  [ 电脑 ]  [ NAS ]        ← 都在 LAN 里
      \      |      /
       \     |     /
        [ 路由器 ]                 ← LAN 与 WAN 的交界
             |
    —— WAN / 互联网 ——            ← 范围更大，不由你管理
```

**这张图是本周的骨架。** 后面四天都在往这张图上填细节：路由器做什么、交换机加在哪、地址写什么、名字怎么翻译。

## 2. 为什么要学

第 1 周你学过「网卡让设备与外界收发数据」，第 2 周学了硬盘和 CPU。但**网络这个东西平时是看不见的** —— 它不像硬盘有容量、不像 CPU 有频率，你只能看到网线插上去之后就「能用了」。

正因为看不见，网络出问题的时候最难判断。不理解 LAN 和 WAN 的边界，会遇到这些问题：

- 为什么在家访问 NAS 很快，出门就不行了？
- 手机连不上 Wi-Fi 和手机连不上某个网站，是同一类问题吗？
- 为什么家里的设备互相能通，但都上不了网？
- 为什么别人说「你的 NAS 在公网上暴露了」听起来很危险？

这些问题的答案都指向同一个判断：

```text
设备是「在 LAN 内」还是「要出 LAN」
↓
决定了它能不能被访问、以及由谁负责转发
```

**这是本周所有内容的基础，也是下周（为什么出门访问不了）的前提。**

## 3. 小白解释

### 3.1 网络：能互相传话的设备

**网络（Network）** 的定义很朴素：**一群能互相传递数据的设备。**

这个定义里有两个要点：

- **设备**：可以是电脑、手机、NAS、打印机、智能电视。
- **能互相传递**：它们之间有某种连接（网线或 Wi-Fi），并且遵守同一套通信规则。

用办公室类比：

> 网络就像一间办公室里的人。只要大家说同一种语言、能互相听见，他们就是一个「通信群体」。

### 3.2 LAN：你家的那个小圈子

**LAN（局域网）** 是你最熟悉的网络 —— **你家里的网络就是 LAN。**

它的特点：

```text
范围小      →  通常只覆盖一个家庭或一栋楼
速度快      →  局域网内的传输速度远高于访问互联网
自己管理    →  路由器是你的，设置由你决定
```

在家里的设备，都通过 Wi-Fi 或网线连到同一个 LAN 上。它们之间可以互相通信，而且**不需要经过互联网**。

### 3.3 WAN：把不同地点连起来的大网络

**WAN（广域网）** 的范围大得多，它把地理位置不同的网络连接起来。

**互联网就是最大的 WAN。** 但 WAN 不只有互联网：

```text
WAN 的例子
├── 互联网                      （全世界）
├── 一个公司连接各地分公司的专线
└── 两个城市之间的数据中心互联
```

家用场景下，你说的 WAN 基本就是互联网。

**关键区别在于「谁管理」：**

| | LAN | WAN |
|---|---|---|
| 范围 | 一个家庭/楼 | 城市、国家、全球 |
| 速度 | 快 | 相对慢 |
| 谁管理 | 你自己 | 运营商 |
| 例子 | 你家 Wi-Fi | 互联网 |

### 3.4 路由器：交界处

LAN 和 WAN 之间需要一个「关口」，数据要进出都必须经过它。

**这个关口就是路由器（Router）。**

```text
LAN 内部           交界           WAN
[ 手机 ]                              |
[ NAS  ]  ←——  [ 路由器 ]  ——→  ——互联网——
[ 电视 ]                              |
```

理解这个位置很重要，因为它解释了两件事：

1. **为什么 LAN 内的设备互通很快** —— 数据不出门，只经过家里的设备。
2. **为什么访问互联网会慢一些** —— 数据要经过路由器、出门、走运营商线路。

**第 2 周学的 Day 5 内容在这里派上用场**：如果路由器成为瓶颈，LAN 内访问也会受影响 —— 因为它也得经过路由器转发。

## 4. 技术解释

### 4.1 网络（Network）

从技术上说，一个网络需要满足几个条件：

- **物理连接**：有线（网线）或无线（Wi-Fi）。
- **统一的通信规则**：常见的是 TCP/IP 协议族（第 5 周会涉及 TCP/UDP）。
- **寻址机制**：能区分不同的设备，也就是 IP 地址（Day 3 的内容）。

**「同一个网络」的技术含义**：设备之间无需经过路由器就能直接通信，通常意味着它们处于同一个地址段内。

### 4.2 LAN（Local Area Network）

局域网的技术特征：

- **由自己管理**：路由器、交换机、地址分配都在你的控制范围内。
- **高带宽低延迟**：现代家用网络内部通常是千兆（1Gbps）或 2.5Gbps，延迟在毫秒级。
- **私有地址空间**：LAN 内使用私有 IP 地址（Day 3 会详细讲）。

**常见的 LAN 设备**：手机、电脑、NAS、打印机、智能家电、机顶盒 —— 只要连在你家网络上，就是 LAN 的一员。

### 4.3 WAN（Wide Area Network）

广域网的技术特征：

- **由运营商维护**：光纤、基站、骨干网这些基础设施都不是你的。
- **需要租用**：你付的宽带费用就是租用 WAN 接入的费用。
- **地址是公网地址**：运营商分配给你一个（或多个）公网 IP。

**家用场景下 WAN 的实际含义**：你家路由器「外网口」之外的那一整个世界。

### 4.4 边界在哪

判断一台设备在 LAN 内还是 LAN 外，问一个问题：

> **它和你的 NAS 之间，数据需要经过你家路由器「出门」吗？**

```text
不需要出门  →  同一个 LAN
需要出门    →  在不同的网络，必须经过 WAN
```

这条判断以后会反复用到，尤其是在第 5 周解释「为什么出门访问不了」的时候。

### 4.5 在家访问 NAS 为什么不经过互联网

这是本周要建立的最重要的一个直觉：

```text
[ 手机 192.168.1.11 ]
        ↓
   [ 路由器 / 交换机 ]       ← 数据只到这里
        ↓
[ NAS 192.168.1.10 ]
```

手机和 NAS 在同一个 LAN 内，数据只需经过家里的网络设备就能到达。**整个过程中，数据没有离开你家。**

这带来两个好处：

- **快**：不经过运营商的线路，速度受限于家里网络的上限。
- **私密**：数据不经过任何外部服务器。

## 5. 类比

把网络想象成**一栋公寓楼**：

- **LAN 是楼内的走廊和住户**：同一栋楼里，你敲隔壁的门只需要走几步路 —— 快，而且不需要出楼。
- **WAN 是楼外的城市**：要去城市的另一端，你得先出楼、上马路、可能还要换乘 —— 慢一些，而且路不是你修的。
- **路由器是大堂的门卫**：它是楼内和楼外的分界。所有进出的东西都要经过它，它决定谁能进来、怎么出去。

这里的关键洞察是：

> **「在同一栋楼里」和「在城市里的另一个地方」，是两种完全不同的关系。**

你在楼内找邻居，走两步就到；但邻居搬到了另一个城市，你就得通过城市的道路系统去找他 —— 而且他还得愿意让你找到（第 5 周的主题）。

## 6. NAS 实际场景

### 6.1 三种访问场景的对比

```text
场景 A：手机在家访问 NAS
  手机 → 路由器 → NAS
  ✓ 快、私密、不经过互联网

场景 B：在公司访问家里的 NAS
  公司电脑 → 互联网 → ？ → NAS
  ✗ 默认访问不了（第 5 周解释）

场景 C：家人在家里用电视看 NAS 上的电影
  电视 → 路由器 → NAS
  ✓ 同样不出门
```

**场景 A 和 C 是本周的能力范围，场景 B 是下周的主题。** 现在只需理解：A、C 能成功，是因为设备在同一个 LAN 里。

### 6.2 三个真实问题

**问题一：为什么在家访问 NAS 很快，看在线视频却会缓冲？**

因为两者走的路径完全不同。NAS 在家里的 LAN 内，数据不出门，速度取决于你家网络的带宽（通常是千兆以上）。在线视频要走 WAN，速度受限于宽带上限和对方服务器的情况。**同样的设备、同样的屏幕，走的路不一样，体验就不同。**

**问题二：家里设备互相能通，但都上不了网，问题可能在哪？**

设备之间能通信，说明 **LAN 部分是正常的**（路由器、交换机、Wi-Fi 都工作）。上不了网，说明问题出在**路由器通往 WAN 的那一段** —— 可能是宽带线路、运营商侧、或者路由器的外网配置。

**这个分层判断很有用**：它让你知道该检查哪里，而不是笼统地说「网坏了」。

**问题三：为什么别人说「NAS 暴露在公网上」很危险？**

因为那意味着你的 NAS 不再只属于 LAN。LAN 内的访问需要「先进入你家网络」这个前提，相当于必须先进楼；而暴露在公网上，等于把它搬到了大街上 —— 任何人在互联网上都能尝试访问它。**安全边界从「楼内」变成了「马路上」**，风险完全不同。第 5 周会详细讲远程访问的正确做法。

### 6.3 画图时先搞清楚两件事

```text
1. 哪些设备在 LAN 内？      → 家里连上你网络的设备
2. 哪条线代表「出门」？      → 路由器通往运营商的那一条
```

所有的网络判断，都可以从这两件事开始。

## 7. 常见误区

### 误区一：互联网就是一个很大的 LAN

不是。LAN 是「自己管理、范围小」的网络，互联网是由无数网络互相连接而成的 WAN。它们的边界、管理方式和地址类型都不同。

### 误区二：有 Wi-Fi 就是有网络

Wi-Fi 只是一种**连接方式**（无线接入），它不等于网络本身，更不等于能上网。你连上了一个 Wi-Fi 但上不了网，说明无线连接是通的，但通往 WAN 的那一段有问题。

### 误区三：在家访问 NAS 要经过互联网

不需要。手机和 NAS 在同一个 LAN 内，数据只经过家里的路由器或交换机，**不出门**。这也是它比访问云端网盘更快、更私密的原因。

### 误区四：LAN 内的设备之间没有延迟

有延迟，只是很小。数据仍然要经过路由器或交换机转发，只是距离短、没有中间环节，所以延迟通常在毫秒级。但如果路由器性能不足（第 2 周学过「瓶颈」），LAN 内也可能变慢。

### 误区五：路由器只是「接网线的盒子」

路由器是 LAN 和 WAN 的边界，承担着转发、地址分配、防火墙等多项工作。Day 2 会详细展开。**把它仅仅理解成「插网线的盒子」，会让你在排障时漏掉关键环节。**
