# 第十八课：IP 地址：内网与公网

> 本课的一句话结论：**IP 地址是设备在网络中的门牌号；你家每台设备都有自己的私有地址，但它们对外共用路由器那一个公网地址。**

## 1. 今天学习什么

今天要掌握 3 个概念：

1. **IP 地址（IP Address）**：在网络中定位一台设备的地址。
2. **私有地址（Private IP）**：只在本地网络内部使用的地址，可以重复。
3. **公网地址（Public IP）**：在互联网上唯一的地址，通常由运营商分配。

你今天要建立的核心结构是：

```text
[ 手机 192.168.1.11 ]   [ NAS 192.168.1.10 ]     ← 私有地址
              \              /
             [ 路由器 ]
        内网口：192.168.1.1  （私有地址）
        外网口：公网地址      （运营商分配）
                  |
            —— 互联网 ——
```

> **本周所有示例都使用 `192.168.x.x` 这类通用示例地址。你真实的公网 IP 不要写进任何公开笔记。**

## 2. 为什么要学

你可能在设置里见过 `192.168.1.1` 这样的数字，也听过「IP 地址」这个词很多次。但它到底解决什么问题、为什么家里和外面的不一样，是本周最值得搞清楚的一环。

不理解 IP 地址的分类，会遇到这些问题：

- 为什么 `192.168.1.10` 在朋友家也是 `192.168.1.10`，却不会冲突？
- 为什么家里三台设备上网，对外却只有一个地址？
- 为什么别人说「你的 NAS 是内网地址，外面访问不到」？
- 为什么路由器需要有两个地址？
- 什么是「地址冲突」？

这些问题的答案指向同一个机制：

```text
私有地址：只在内部有意义，可以重复使用
公网地址：在互联网上唯一，数量有限
路由器负责在两者之间转换
```

**这也是理解第 5 周「为什么出门访问不到」的直接前提。**

## 3. 小白解释

### 3.1 IP 地址：网络中的门牌号

数据要在网络中传递，就必须知道「送到哪台设备」。**IP 地址就是这个「送到哪」的标识** —— 相当于网络世界的门牌号。

一台设备要和其他设备通信，必须先有一个 IP 地址。没有地址，数据不知道往哪送。

**关键点：IP 地址标识的是「位置」，不是「设备本身」。** 同一台手机，在家里的网络和在公司网络里，会拿到不同的 IP 地址 —— 就像同一个人，在公司工位和家里的门牌号不同。

### 3.2 私有地址：楼内的房间号

**私有地址（Private IP）** 只在**本地网络内部**使用。

常见的私有地址范围：

```text
192.168.x.x      ← 家庭网络最常用
10.x.x.x         ← 企业网络常用
172.16.x.x ~ 172.31.x.x
```

**最重要的一点：私有地址可以重复。**

你家可以用 `192.168.1.10`，你朋友家也可以用 `192.168.1.10`，全世界几亿个家庭都在用 —— **因为它们是「内部房间号」，不出门，所以不会冲突。**

用公寓楼类比：

> 私有地址就像**楼内的房间号**。「3 号楼 502 室」这个说法，在你住的小区里能定位到一户人家。但如果全国每个小区都有 502 室，那单说「502 室」就没意义 —— **它只在自己楼里有效。**

### 3.3 公网地址：全世界的唯一门牌

**公网地址（Public IP）** 是在互联网上**唯一**的地址。

它由运营商分配给你，通常只有**一个**，由路由器持有。

**为什么强调「唯一」？** 因为互联网上不能有两个 `93.184.216.34` —— 就像快递地址不能有两户人家用同一个门牌号，否则快递不知道该送哪。

**为什么强调「只有一个」？** 因为你家里可能有十几台设备，但对外只共用路由器那一个公网地址。家里设备再多，也不需要更多的公网地址。

### 3.4 两个地址并存

于是路由器上出现了两个地址：

```text
路由器
├── 内网口：192.168.1.1     ← 私有地址，面向家里的设备
└── 外网口：公网地址         ← 运营商分配，面向互联网
```

路由器站在两个网络之间，一边用私有地址和家里的设备说话，一边用公网地址和互联网说话。**它是连接两套「门牌号系统」的翻译官。**

（这个翻译过程叫 NAT，第 5 周详细讲。今天只需知道它存在。）

## 4. 技术解释

### 4.1 IP 地址的结构

IPv4 地址是 32 位数字，通常写成四组十进制数：

```text
192.168.1.10
 ↑   ↑   ↑  ↑
 每段 0–255
```

地址分为两部分：

- **网络部分**：标识「在哪个网络」。
- **主机部分**：标识「网络里的哪台设备」。

**如何划分这两部分由子网掩码决定。本周不要求做子网计算** —— 你只需要知道有这回事，以及「同一个网络里的设备，网络部分相同」。

### 4.2 私有地址范围

RFC 1918 定义的私有地址范围：

| 范围 | 常见用途 |
|---|---|
| `10.0.0.0` ~ `10.255.255.255` | 大型企业网络 |
| `172.16.0.0` ~ `172.31.255.255` | 中型网络 |
| `192.168.0.0` ~ `192.168.255.255` | 家庭网络最常见 |

**这些地址不会在互联网上被路由。** 也就是说，一个发往 `192.168.1.10` 的数据包，在互联网上会被丢弃 —— 因为互联网上的路由器不认这个地址。**这就是「私有地址外面访问不到」的根本原因。**

### 4.3 公网地址

公网地址由 IANA 分配、运营商下发。你的宽带账号对应的就是一个公网地址（有些情况下运营商可能不给你独立的公网地址，那会带来额外限制，属于进阶话题）。

特点：

- **全球唯一**：互联网上不能重复。
- **数量有限**：IPv4 地址总量约 43 亿个，早已分配完毕，这是 IPv6 出现的原因之一。
- **可能变化**：很多家用宽带的公网地址是动态的，会随时间变化（第 5 周会讲 DDNS 如何应对）。

### 4.4 地址冲突

如果同一个网络里有两台设备用了相同的 IP，就产生**地址冲突**。表现是其中一台或两台都无法正常通信。

常见原因：

- 手动设置了固定地址，但和 DHCP 分配的范围重叠。
- 两台设备都设了同一个静态地址。

**排查思路**：如果某台设备突然上不了网，而其他设备正常，可以先怀疑地址冲突。

## 5. 类比

用**快递**来理解这一整套机制：

- **私有地址是「楼内房间号」**：305 室、508 室。整栋楼里唯一，出了这栋楼就没人认识。
- **公网地址是「小区地址 + 门牌」**：这是快递员真正需要的、在全世界唯一能找到你的地址。
- **路由器是小区传达室**：快递送到小区地址，传达室看到「305 室」就知道该送到哪户，再自己送上门。

这个类比解释了三个关键点：

**第一，为什么私有地址可以重复**：全国有几万个小区，每个小区都有 305 室，这没关系 —— 因为快递员只认小区地址，305 室由传达室自己处理。

**第二，为什么外面访问不到你家的 NAS**：你家的 NAS 只有「楼内房间号」（私有地址）。外面的人不知道你住哪个小区（公网地址），就算知道，他也没法直接喊「305 室」—— **必须经过传达室（路由器）的转达**，而传达室默认不帮忙转达外部来找内部设备的请求。

**第三，为什么需要一个公网地址就够了**：一个小区的快递都送到同一个传达室，再由传达室分发。不需要给每户人家都配一个独立的对外地址。

## 6. NAS 实际场景

### 6.1 在你自己的网络上查看地址

你在 NAS 或路由器设置里通常能看到这几类信息：

```text
NAS 的 IP 地址        →  一般是 192.168.1.x（私有地址）
路由器的内网地址       →  一般是 192.168.1.1
子网掩码              →  决定哪些地址属于同一个网络
默认网关              →  指向路由器（出门的必经之路）
DNS 服务器            →  通常是路由器自己的地址
```

**「默认网关」这个概念值得注意**：它告诉设备「要出这个网络，去找谁」。在家庭网络里，它就是路由器。

### 6.2 三个真实判断

**场景一：为什么 `192.168.1.10` 在外面访问不到**

因为它是私有地址，互联网上的路由器不认这个地址，数据包会在路上就被丢弃。要能从外面访问，必须通过某种方式让请求先到达你的公网地址，再由路由器转交给内网设备 —— 这是第 5 周的主题。

**场景二：家里三台设备上网，对外是一个地址还是三个**

**一个。** 三台设备各自有私有地址（如 `.11`、`.12`、`.13`），但它们发出的请求在路由器那里会「共用」同一个公网地址出去。路由器负责记住「哪个请求是谁发出的」，把回应送回来。

**这也是家用网络能正常运行的基础** —— 否则家里每台设备都需要一个公网地址，而 IPv4 地址早就耗尽了。

**场景三：设备突然上不了网，其他设备正常**

可以先检查两处：一是地址是否冲突（两台设备用了同一个 IP），二是这台设备拿到的地址是否正常（比如拿到了 `169.254.x.x` 这种特殊地址，通常意味着它没能从 DHCP 拿到地址 —— 那是明天的内容）。

### 6.3 一个隐私提醒

**你的真实公网 IP 是一种个人信息。** 它可以用来大致定位你的地理位置和运营商。

所以在写学习笔记、截图路由器设置页面、或者发布排障记录时：

```text
✓ 可以用：192.168.1.10、10.0.0.1 这类示例地址
✗ 不要写真实的公网 IP、域名、宽带账号
```

本仓库的[隐私原则](https://github.com/skylardai0718-byte/nas-ai-learning#隐私原则)也说明了这一点。

## 7. 常见误区

### 误区一：`192.168.1.10` 是可以直接在互联网上访问的地址

不能。它是私有地址，只在本地网络内部有意义。互联网上的路由器不会转发发往私有地址的数据包 —— 这也是家庭网络天然具备一定安全性的原因。

### 误区二：家里每台设备都有自己的公网地址

不对。家里通常是**一个**公网地址，由路由器持有。所有设备通过它对外通信，路由器负责区分不同设备的连接。

### 误区三：私有地址会因为和别人重复而冲突

不会。私有地址只在**同一个网络内部**需要唯一。你家和你朋友家用同样的 `192.168.1.x` 完全没有问题，因为它们是两个互不相通的网络。

**真正的冲突发生在同一个网络内部**，比如你家两台设备用了同一个地址。

### 误区四：IP 地址标识的是设备

不准确。IP 地址标识的是「设备在网络中的位置」。同一台笔记本，在家和在公司会拿到不同的 IP 地址。

### 误区五：只有一个公网地址会不够用

够用。家用场景下的十几台设备共用一个是常态。路由器会分别记录每条连接是由哪台内网设备发起的，据此把回应送回正确的设备。
