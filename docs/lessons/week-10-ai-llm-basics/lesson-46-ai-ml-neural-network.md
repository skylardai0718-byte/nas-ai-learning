# 第四十六课：AI、机器学习与神经网络

> 本课的一句话结论：**AI、机器学习、神经网络不是三件并列的事，而是层层包含的三个圈 —— AI 最大，机器学习是其中一种做法，神经网络又是机器学习里的一种方法。**

## 1. 今天学习什么

今天要掌握 3 个概念：

1. **AI（人工智能，Artificial Intelligence）**：让机器表现出「像人一样做事」的能力，范围最大的那个圈。
2. **机器学习（Machine Learning）**：让机器从大量例子里自己总结规律，而不是由人写死规则。
3. **神经网络（Neural Network）**：实现机器学习的一种方法，灵感来自大脑神经元之间的连接。

你今天要建立的核心结构是这张包含关系图：

```text
AI（人工智能）          ← 最大的圈
└── 机器学习            ← AI 里的一种做法
    ├── 神经网络        ← 机器学习里的一种方法
    │   └── LLM         ← 下周、以及之后一直要用的东西
    └── 其他方法
```

读出这张图的方式是：**越往下，范围越小、也越具体。** 一个 LLM 一定也是神经网络、也是机器学习、也是 AI；但一个早期的规则系统可以算 AI，却不是机器学习。

## 2. 为什么要学

你大概听过很多说法：AI、机器学习、深度学习、神经网络、大模型……这些词经常被混着用，让人以为它们是差不多的东西。

但**它们其实是包含关系，不是并列关系**。不把这一层理清，会遇到这些问题：

- 为什么有人说「AI 早就有，只是最近才火」？如果 AI 就是大模型，那这句话就说不通。
- 为什么「机器学习」和「传统写程序」被说成两种不同的思路？差别到底在哪？
- 为什么神经网络这么火，却又有人说机器学习「不只是神经网络」？
- 为什么「训练」这个词老是和 AI 绑在一起？它到底训练的是什么？
- 为什么后面的课程总把 LLM 挂在「AI」这个大类下面，而不是单独讲？

**这是整个 AI 阶段的入口。** 把这张包含关系图先立起来，后面所有的概念 —— 模型、参数、token、推理 —— 才有地方安放。

## 3. 小白解释

### 3.1 三个圈，而不是三样东西

先记住一件事：**这三个词不是并列的三样东西，而是三个越缩越小的圈。**

```text
─────────────────────────────
│  AI（人工智能）             │
│  ┌───────────────────────┐  │
│  │ 机器学习               │  │
│  │  ┌─────────────────┐  │  │
│  │  │ 神经网络         │  │  │
│  │  │  ┌───────────┐  │  │  │
│  │  │  │   LLM     │  │  │  │
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

**AI 是最外面的圈**：只要让机器做出「像人一样」的事 —— 下棋、认字、翻译、对话 —— 都算 AI。早期的 AI 靠人把规则一条条写死，也照样叫 AI。

**机器学习是 AI 里的一种做法**，也是现在最主要的一种。

**神经网络又是机器学习里的一种方法。** 它特别擅长从海量数据里找规律，所以现在最主流，但它**不是**机器学习的全部。

用一句话记住：

> **AI 是一个目标，机器学习是一种达成目标的思路，神经网络是这种思路下的一种具体工具。**

### 3.2 机器学习和传统编程，谁写规则

这是本课最关键的一处对比。

**传统编程**：人把规则想清楚、写下来，电脑照着执行。

```text
传统编程：人写规则  +  数据  →  得到答案
```

比如你想让程序判断一封邮件是不是垃圾邮件，传统做法是人去写规则：「标题里有『中奖』就算垃圾邮件」。规则是人一条条想出来的。

**机器学习**：反过来 —— 人给出**大量的例子**，让机器自己从中总结出规律。

```text
机器学习：大量例子（数据 + 正确答案）  →  机器总结出规则
```

同样判断垃圾邮件，机器学习做法是：给人手标记好的一万封邮件（哪些是垃圾、哪些不是），机器自己去琢磨「哪些特征和垃圾邮件有关」，最后自己总结出一套判断规则。

**这个「机器总结出来的规则」，就是模型。** 你不需要理解它是怎么总结的 —— 事实上，连造它的人也不完全清楚里面每一条规则是什么。

一句话记住这个反转：

```text
传统编程：先有规则，后有答案
机器学习：先有答案（例子），反推出规则
```

### 3.3 神经网络为什么叫这个名字

**神经网络（Neural Network）** 的名字来自生物学：它模仿的是大脑里神经元相互连接、传递信号的方式。

一个神经网络由很多很多个「小计算单元」组成，它们分层排列、互相连接。数据从一头进来，经过一层层的处理，从另一头出去一个结果。

```text
输入  →  [一层单元]  →  [一层单元]  →  [一层单元]  →  输出
         互相连接、逐层处理
```

它的强项是**从非常复杂的数据里找出规律** —— 比如「这张图里是不是一只猫」这种几乎写不出规则的任务。

但要记住边界：

> **神经网络是一种方法，不是机器学习的全部，也不是 AI 的全部。** 机器学习里还有别的、不需要神经网络的方法。

### 3.4 今天不学数学

这一周是概念周。**你不需要看懂神经网络内部怎么算的**，也不需要任何数学。

这一周你只要做一件事：**把概念的位置摆对。** 知道谁包含谁、谁是谁的一种，就已经够了。

## 4. 技术解释

### 4.1 AI 的范围

AI（人工智能）指让机器完成通常需要人类智能的任务，比如推理、学习、感知、理解语言、做决策。

它的范围**刻意定得很宽**，因为它是一个目标，而不是一种技术。历史上实现这个目标的方式换过好几代：

```text
早期：人写死规则的专家系统        → 也算 AI
现在：以机器学习为主，尤其是神经网络 → 也属于 AI
```

所以「AI 早就有了」这句话是对的 —— 变的不是目标，而是**实现目标的方法**。

### 4.2 机器学习的定义

机器学习是一种让机器**从数据中自动改进表现**的方法。它的核心特征是：

- **不靠人逐条写规则**，而是从数据中总结规律。
- 数据里通常包含「输入」和「期望的输出」，机器据此调整自己。
- 学到的东西被保存下来，这个产物就是**模型（Model）** —— 明天会详细讲。

机器学习的范围很广，除了神经网络，还包括决策树、支持向量机等一系列方法。它们在数据量小、需要可解释性的场景里仍然有用。

### 4.3 神经网络的位置

神经网络是机器学习中的一类方法，特点是：

- 由大量**互相连接的计算单元**分层组成。
- 通过**调整内部数值**来学习（这些数值就是明天要讲的「参数」）。
- **特别擅长处理复杂、难以用规则描述的任务**：图像、语音、语言。
- 通常需要**较多的数据和算力**才能训练好。

**LLM 就是神经网络中的一个特例**：专门处理语言、而且规模很大的神经网络。

### 4.4 为什么现在才火

神经网络的思路并不新，但很长时间里没能大放异彩。原因不在概念，而在**条件**：

- 数据量不够大。
- 算力不够强。
- 训练方法不够成熟。

当这些条件逐渐具备后，神经网络才在语言、图像等任务上大幅领先。**这提醒你一件事：一个方法能不能用起来，常常不只取决于方法本身，还取决于配套的条件是否到位。**

## 5. 类比

把这三个概念想象成**「出行」这件事**：

```text
出行（目标）          ← 相当于 AI
└── 坐车（一种思路）  ← 相当于机器学习
    └── 汽车（一种工具）← 相当于神经网络
```

- **出行是最外层的目标**：走路、骑车、开车都算，只要把人从 A 送到 B。就像只要能表现出智能，都叫 AI。
- **坐车是达成出行的一种思路**：它规定了大方向 —— 用机械动力、不用人力。就像机器学习规定了「从数据里学，而不是人写规则」这个大方向。
- **汽车是坐车思路下的一种具体工具**：它是最主流、最有劲的那种，但也有别的选择（摩托、公交）。就像神经网络是最主流的机器学习方法，但不是唯一。

**这个类比能解释什么？**

- 它能解释**为什么这四个词不冲突**：出行、坐车、汽车、越野车，说的是一层套一层的关系，而不是四件互相打架的事。
- 它能解释**为什么「没有汽车的时代也有出行」**：目标可以很早就存在，工具是后来才出现的。
- 它能解释**为什么汽车最主流却不能说它等于出行**：同样的道理，神经网络最主流，但不能说神经网络就等于 AI。

## 6. NAS 实际场景

### 6.1 三个真实判断

**场景一：你听说「AI 早就有，只是最近才火」，为什么说得通？**

因为 AI 是**目标**，不是某一种技术。目标一直都在，变的是实现目标的方法 —— 从人写死规则，换成让机器从数据里学。你不需要「AI 出现了」这个说法，只需要知道它一直在，方法换了代。

**场景二：你看到「机器学习速成课」和「神经网络速成课」，先学哪个？**

先弄清它们的层级。神经网络是机器学习里的一种方法 —— 如果一上来就扎进神经网络的细节，你会以为「机器学习 = 神经网络」，后面遇到非神经网络的方法就会混乱。**先有地图，再看细节。**

**场景三：为什么讲 NAS 上跑 AI，最后总要落到「LLM」上？**

因为这三个圈是一层层收窄的：

```text
AI  ── 太宽，什么都算
机器学习 ── 是一种思路，但方法有好几种
神经网络 ── 是一种方法，但仍然很泛（也能处理图像、语音）
LLM  ── 终于具体到「处理语言」，才是你在 NAS 上真正会用到的东西
```

**你手上的 NAS 能跑的东西，是这条链最里面那一层。**

### 6.2 一张对照表

| 概念 | 中文 | 是什么层次的词 | 一个例子 | 不是什么 |
|---|---|---|---|---|
| AI | 人工智能 | 目标、最大的圈 | 任何表现智能的系统 | 不等于「大模型」 |
| Machine Learning | 机器学习 | 一种思路 | 从数据里学规律 | 不等于「神经网络」 |
| Neural Network | 神经网络 | 一种方法 | 分层连接的单元网络 | 不等于「机器学习全部」 |
| LLM | 大语言模型 | 一种具体模型 | 处理语言的大神经网络 | 不等于「AI 全部」 |

## 7. 常见误区

### 误区一：AI、机器学习、神经网络是并列的三个东西

它们是**层层包含**的关系，不是并列。AI 最大，机器学习是其中一种做法，神经网络又是机器学习里的一种方法。把包含关系当成并列，会让后面所有概念都没有地方安放。

### 误区二：AI 就等于大语言模型

大语言模型只是 AI 这个大类里，非常具体的一小支。AI 还包括图像识别、语音、下棋、自动驾驶等很多方向，也包括那些根本不靠机器学习的早期方法。把 AI 缩成「聊天机器人」，是对这个领域最大的误解之一。

### 误区三：机器学习就是由人写更聪明的规则

正相反。机器学习的标志性特点恰恰是**人不写规则**，而是给大量例子，让机器自己总结出规则。如果规则还是人一条条写的，那属于传统编程或早期的规则系统，不是机器学习。

### 误区四：神经网络是机器学习的唯一方法

神经网络是其中最主流的一种，但机器学习的家族里还有决策树、支持向量机等方法。它们在数据较少或需要看清判断依据的场景里仍有价值。「最主流」不等于「唯一」。

### 误区五：学 AI 必须先学懂数学

对本课程来说，**不需要**。数学是理解「内部怎么算」的工具，但理解「概念是什么、彼此什么关系、边界在哪」，不需要任何推导。你这一周的目标是摆正位置，不是会算。等把地图建立清楚了，再决定要不要深入数学，是更合理的顺序。
