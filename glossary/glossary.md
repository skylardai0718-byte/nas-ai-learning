# Glossary

这个术语表只收录已经在课程中正式学过的词。解释会随着理解加深而修订，而不是一次写成百科全书。

| Term | 中文 | 一句话解释 | 分类 | 首次出现 |
|---|---|---|---|---|
| Computer | 计算机 | 接收信息、按照指令处理信息，并能保存或输出结果的系统。 | Hardware / Software | Phase 0, Lesson 1 |
| Hardware | 硬件 | 能实际触摸到、负责计算、临时记忆、长期存储和联网的物理部件。 | Hardware | Phase 0, Lesson 1 |
| Operating System | 操作系统 | 管理硬件，并为应用程序提供统一运行环境的基础软件。 | Software | Phase 0, Lesson 1 |
| Application | 应用程序 | 使用操作系统提供的能力，完成某个具体任务的软件。 | Software | Phase 0, Lesson 1 |
| NAS | 网络附加存储 | 连接到网络、以存储和共享数据为核心用途的计算机。 | Storage | Phase 0, Lesson 1 |
